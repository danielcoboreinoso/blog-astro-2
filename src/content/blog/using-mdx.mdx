Este blog incluye la integración [@astrojs/mdx](https://docs.astro.build/en/guides/integrations-guide/mdx/) configurada en `astro.config.mjs`. Si no te interesa MDX, puedes quitar la integración del archivo de configuración.

## ¿Qué es MDX?

MDX es una variante de Markdown que permite escribir JavaScript y sintaxis JSX. Esto abre la puerta a [mezclar componentes con tu contenido](https://docs.astro.build/en/guides/integrations-guide/mdx/#mdx-in-astro), por ejemplo para crear alertas, gráficos interactivos o bloques reutilizables.

Si ya tienes artículos escritos en MDX, migrarlos a Astro es muy directo.

## Ejemplo

Así se importa y usa un componente dentro de un archivo MDX. Al abrir esta página en el navegador deberías ver el enlace interactivo:

import HeaderLink from '../../components/HeaderLink.astro';

<HeaderLink href="#" onclick="alert('¡He hecho clic!')">
	Componente incrustado en MDX
</HeaderLink>

## Más información
